# 网安攻防实验

## 实验目标完成

- [x] 自定义靶场搭建
- [x] 内部子网数量>=2 数量为3
- [x] 攻击链路上的靶标更换数量>=2 数量为5
- [x] 攻击链路验证通过（攻击者不能直接在靶机上进行攻击，需要使用独立 IP）
